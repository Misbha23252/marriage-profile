MISBHA K - MARRIAGE PROPOSAL WEBSITE

SHOWING / HIDING THE EDITING TOOLS (eye icon)
- All editing tools are hidden by default so visitors see a clean website.
- Click the faint green EYE icon (top-left corner) to reveal the editing tools:
  photo Save/Remove buttons, the status text, and the "✎ Edit Text" button.
- Click the eye icon again to hide everything and return to the clean view.

TEXT EDITING (About, Family, Gallery, Values, Contact, Hero)
- With the eye icon ON, click the "✎ Edit Text" button (bottom-right corner).
- Every text item (names, details, headings, address, quote, etc.) becomes
  clickable — click and type to change it.
- Click "Save Changes" to persist all text in the browser.
- Click "Done" to leave edit mode.
- Click "Reset All" to restore the original text.

PHOTO MANAGEMENT (with the eye icon ON)
- Click Add Photo to select an image.
- Click Save to persist it in the browser.
- Reopen the same website on the same browser/device and the saved photos remain.
- Click Remove to delete a saved photo.
- You can then add and save a replacement photo.

MOBILE NAVIGATION
- On phones, tap the ☰ menu button (top-right of the nav bar) to open the
  section links (About, Family, Gallery, Values, Contact). Tap a link to jump
  there; the menu closes automatically.

IMPORTANT:
This version uses browser local storage, so photos AND text edits are saved
locally on the device/browser. They are NOT uploaded to a public server.

For a truly shareable public link where saved photos and text appear for EVERY
visitor, the next version needs online image storage/database (or bundled
content in the published website). That is a separate hosting/backend step.
